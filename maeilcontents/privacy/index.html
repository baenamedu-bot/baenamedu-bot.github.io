매일콘텐츠 개인정보처리방침

시행일: 2026년 8월 20일 · 최종 수정일: 2026년 8월 20일

유앤미스튜디오(이하 "회사")는 매일콘텐츠(이하 "앱")를 제공하면서 이용자의 개인정보를 수집하지 않습니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

요약

회사는 이용자로부터 어떤 개인정보도 수집·저장·전송하지 않습니다. 앱에는 회원가입과 로그인이 없으며, 이용자가 입력한 모든 내용과 API 키는 이용자 기기 안에만 저장됩니다. 회사는 이를 열람할 수 없습니다.

1. 수집하는 개인정보

없습니다. 앱은 회원가입, 로그인, 이메일 수집, 연락처 접근, 위치 수집, 광고 식별자 수집을 하지 않습니다. 회사는 서버를 운영하지 않으며 이용자 데이터를 전송받지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 이용자 기기의 브라우저 저장소(IndexedDB)에만 저장됩니다.

  • 브랜드 설정 — 업종, 회사 소개, 문체, 안내 문구, 해시태그, 연락처 등 이용자가 직접 입력한 내용
  • 주제 목록과 각 주제의 상태
  • 생성한 프롬프트와 결과물 이력
  • 이용자가 입력한 Gemini API 키

이 정보는 기기를 벗어나지 않습니다. 앱을 삭제하거나 브라우저 저장 데이터를 지우면 함께 삭제되며, 회사는 이를 복구할 수 없습니다.

3. API 키 취급

앱은 이용자가 직접 발급받은 Google Gemini API 키를 사용하는 방식(BYOK)으로 동작합니다.

  • 키는 이용자 기기에만 저장되며 회사 서버로 전송되지 않습니다. 회사는 서버를 두고 있지 않습니다.
  • 콘텐츠를 생성할 때 앱은 이용자 기기에서 구글 서버로 직접 요청을 보냅니다. 이때 이용자가 입력한 주제·브랜드 설정 등 프롬프트 내용이 구글로 전송됩니다.
  • 구글이 해당 데이터를 처리하는 방식은 구글 개인정보처리방침과 Gemini API 약관을 따릅니다.
  • API 사용료는 키를 발급받은 이용자에게 구글이 직접 청구합니다. 회사는 관여하지 않습니다.

4. 제3자 제공 및 위탁

회사가 이용자 정보를 제3자에게 제공하거나 처리를 위탁하는 일은 없습니다. 수집하는 정보가 없기 때문입니다. 위 3항의 구글 요청은 이용자 본인의 키로 이용자 기기에서 직접 이루어지는 것으로, 회사를 거치지 않습니다.

5. 광고 및 분석 도구

현재 버전에는 광고와 분석 도구가 포함되어 있지 않습니다. 추후 광고가 도입될 경우 이 방침을 사전에 개정하고 앱 내에서 고지합니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 개인정보를 수집하지 않습니다.

7. 이용자의 권리

회사가 보관하는 이용자 정보가 없으므로 열람·정정·삭제를 회사에 요청할 대상이 없습니다. 기기에 저장된 내용은 앱 안에서 직접 삭제하거나, 앱을 삭제하여 전부 지울 수 있습니다.

8. AI 생성물에 대한 안내와 신고

앱이 만들어 내는 문구는 인공지능이 생성한 것으로 사실과 다를 수 있습니다. 이용자는 게시 전에 내용을 확인할 책임이 있습니다. 부적절한 생성물을 발견한 경우 아래로 신고해 주시기 바랍니다.
