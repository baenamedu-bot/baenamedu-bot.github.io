자주 묻는 질문

API 키가 꼭 있어야 하나요?

아니요. 키가 없어도 주제 관리, 프롬프트 만들기, 카드뉴스 이미지 만들기는 모두 됩니다. 만든 프롬프트를 쓰시던 제미나이·챗GPT에 붙여넣어 결과를 받으면 됩니다. 키를 넣으면 앱 안에서 글까지 바로 만들어집니다.

Gemini API 키는 어디서 받나요?

Google AI Studio에서 발급받을 수 있습니다(무료 등급 있음). 앱의 설정 → ‘API 키가 있어요’ → 키 붙여넣기 → ‘연결 확인’ 순서로 넣으세요. 사용료가 생기면 키를 발급받은 분께 구글이 직접 청구합니다.

카드뉴스 이미지는 어떻게 저장하나요?

생성 화면의 카드뉴스 탭에서 6장 문구를 채운 뒤 하단 ‘이미지 저장’을 누르세요. 공유 창이 열리면 ‘이미지 저장’으로 사진 앱에 넣거나 인스타그램·스레드·카카오톡으로 바로 보낼 수 있습니다. 문구는 한 장씩 직접 쓰거나, AI 답변을 통째로 붙여넣어 한 번에 채울 수 있습니다.

매일 알림은 어떻게 켜나요?

설정 → 매일 알림에서 시각을 고르고 ‘매일 알림 켜기’를 누르세요. 휴대폰 앱에서만 쓸 수 있습니다. 알림이 오지 않으면 휴대폰 설정에서 매일콘텐츠의 알림 권한을 확인해 주세요.

입력한 내용은 어디에 저장되나요?

모두 이용하시는 기기 안에만 저장됩니다. 회원가입이 없고 회사 서버로 보내지 않습니다. 그래서 앱을 지우거나 다른 기기에서 열면 내용이 보이지 않습니다.

연결 확인에서 오류가 나요.

화면에 나온 안내와 오류 원문을 함께 보내 주세요. 대부분 키를 잘못 붙여넣었거나, 키에 사용 한도가 걸렸거나, 선택한 모델을 쓸 수 없는 경우입니다.
