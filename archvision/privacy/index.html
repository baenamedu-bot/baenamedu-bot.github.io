아크비전 개인정보처리방침

시행일: 2026년 7월 24일 · 앱: 아크비전 (kr.younme.archvision) · 개발자: 유앤미스튜디오(you&me studio)

1. 개요

아크비전(이하 "앱")은 회원가입이나 로그인 없이 동작하며, 개발자가 운영하는 서버가 없고 개발자가 직접 수집·저장하는 개인정보도 없습니다. 앱의 모든 설정 값은 이용자의 기기에만 저장됩니다.

2. Gemini API 키 (이용자 직접 입력)

앱은 이용자가 직접 발급받은 Google Gemini API 키를 입력하여 사용하는 방식(BYOK)입니다. 입력한 API 키는 이용자의 기기(앱 내부 저장소)에만 저장되며, 개발자에게 전송되거나 외부 서버에 저장되지 않습니다. 앱 내 "키 삭제" 기능 또는 앱 삭제로 언제든지 제거할 수 있습니다.

3. 이미지 처리

이용자가 편집을 위해 업로드하는 건축 이미지와 입력 텍스트는 AI 처리를 위해 이용자 본인의 API 키로 Google Gemini API에 직접 전송됩니다. 이 과정에서 개발자는 이미지·텍스트·결과물에 접근할 수 없습니다. Google의 데이터 처리에 대해서는 Google 개인정보처리방침 및 Gemini API 이용약관을 참고하세요.

4. 저장 및 공유

생성된 이미지는 이용자가 저장 버튼을 누른 경우에만 기기 갤러리에 저장되며, 공유 기능은 기기의 기본 공유 기능을 통해 이용자가 선택한 대상에게만 전달됩니다.

5. 광고 및 분석

앱은 광고를 표시하지 않으며, 별도의 분석(애널리틱스)·추적 도구를 사용하지 않습니다.

6. 아동의 개인정보

앱은 특정 연령을 대상으로 하지 않으며, 개발자가 아동의 개인정보를 직접 수집하지 않습니다.

7. AI 생성 콘텐츠 신고

부적절한 AI 생성 결과물은 앱 내 신고 버튼을 통해 mybestlife@younme.ai.kr로 신고할 수 있습니다.

8. 문의

개인정보 관련 문의: mybestlife@younme.ai.kr

ARCH-VISION — Privacy Policy

Effective: July 24, 2026 · App: ARCH-VISION (kr.younme.archvision) · Developer: you&me studio

1. Overview

ARCH-VISION (the "App") works without any account or sign-in. The developer operates no server and does not collect or store any personal information. All settings are stored only on your device.

2. Gemini API key (BYOK)

The App uses your own Google Gemini API key. The key is stored only on your device and is never transmitted to the developer or any third-party server. You can remove it anytime via the in-app "delete key" function or by uninstalling the App.

3. Image processing

Images and text you submit for editing are sent directly to the Google Gemini API using your own key. The developer has no access to your images, prompts, or results. See the Google Privacy Policy and Gemini API Terms.

4. Ads & analytics

The App shows no ads and uses no analytics or tracking tools.

5. Children

The App is not directed at children, and the developer does not knowingly collect personal information from children.

Privacy inquiries / AI-content reports: mybestlife@younme.ai.kr
